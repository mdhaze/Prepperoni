# Prepperoni - LOCAL AI to run on 32gb memory MAC, to provide hard core survival info 

Currently testing with Qwen3:30b-a3b and Ollama CLI

Prepperoni is a survival reference that runs on your own computer after the network is gone. It is for nuclear accidents, pandemics, storms, war, and long power cuts. It does not call a server, it does not need an account, and it does not wait for an official broadcast before it will show you a page you already stored.

You install it once, while you still have a connection. That download includes the program and about 10,000 pages of field manuals, civil-defense guides, and medical and sanitation references, already split and indexed. The language model itself is a separate download of about 19 GB. After that, the machine can be offline. A normal 32 GB Apple-silicon Mac is the machine it is built for.

You ask in plain language. “How do I make this creek water drinkable?” “How do I build a shelter in the rain?” “What do I do about a fever and diarrhea?” The first line is the action, in short sentences, written for someone who is wet, sick, and tired. One warning follows. The last line names the manual and the page the action came from. If that page is not in the library, it says so instead of guessing.

Doses are not guessed. Bleach strength, potassium iodide, and radiation stay-time come from fixed tables shipped with the program. If you do not give it the bleach percentage or the meter reading, it asks one question and waits. Potassium iodide is described as thyroid protection against radioactive iodine only. It will still show the dose row if no official has told you to take it.

It does not know your weather, your location, or what is in your house unless you type it. It is not a doctor, and it will not invent an antibiotic dose. Ten thousand pages make it useful across a lot of bad situations. They do not make it current, and they do not make a missing page appear.
